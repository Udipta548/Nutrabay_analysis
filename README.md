# Nutrabay Hiring Funnel Dashboard

## Overview
An interactive hiring analytics dashboard built in Power BI to give 
management real-time visibility into recruitment performance across 
all hiring stages and departments.

## Problem Statement
Management lacked visibility into hiring performance — specifically 
around total applicants, stage-wise conversion rates, time to hire, 
and drop-off points in the funnel.

## Solution
A fully interactive Power BI dashboard built on structured Excel data 
covering 6 months and 6 departments tracking 1,240 applicants across 
7 hiring stages from Applied to Hired.

## Dashboard Features
- KPI Cards — Total Applicants, Total Hired, Avg Time to Hire, Offer Acceptance %
- Funnel Chart — Stage-wise drop-off from Applied to Hired
- Bar Chart — Department-wise applicant comparison
- Line Chart — Monthly time to hire trend with trend line
- Conversion Table — Stage conversion % with red/green conditional formatting
- Slicers — Filter by Department and Month interactively

## Key Insights
- Highest drop-off at Screening stage (50%) — suggests need for better resume filtering
- Time to hire improved from 31 days (Oct 2024) to 26 days (Mar 2025)
- Engineering has highest applicant volume (420 out of 1,240)
- Offer acceptance rate is strong at 81.3%

## Tools Used
- Power BI Desktop — Dashboard and visualizations
- Microsoft Excel — Data structuring and storage
- Claude AI — Data planning and layout assistance

## Data Structure
| Sheet | Description |
|---|---|
| Hiring_Funnel | 7 stages with candidates, conversion %, drop-off % |
| Department_Data | 6 departments with applicant breakdown |
| Monthly_Trend | 6 months of applications, hired, time to hire |
| Time_to_Hire | Department-wise time to hire across 6 months |

## Files in this Repository
- Hiring_Dashboard_PowerBI_Data_Fixed.xlsx — Source data file
- Nutrabay_Hiring_Dashboard.pbix — Power BI dashboard file
- README.md — Project documentation

## How to Use
1. Download both files
2. Open the .pbix file in Power BI Desktop
3. Update data source path to point to the Excel file
4. Refresh data and explore the dashboard
